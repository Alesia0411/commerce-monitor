# 辅助采集与受控浏览器采集

## 已实现的两条路径

**辅助采集：**选择自有商品 → 粘贴有权处理的页面文字或上传 PNG/JPEG 截图 → 提取候选 → 查看原文、截图及字段依据 → 人工确认实际规格和商品编号 → 登记并关联。

**受控浏览器：**选择自有商品及管理员批准的站点 → 以标题和类目生成关键词 → 浏览器访问搜索页 → 根据站点选择器打开最多 3 个详情页（API 上限 5）→ 截取可见页面、读取可见正文 → 共用候选提取与审核流程。

两个模式都不绕过登录或验证码，不调用平台隐藏接口；不自动发布商品、不下单。当前未启用任何真实购物平台，启用配置代表部署者已经核验站点与用途的访问许可，不是程序授予的平台授权。

## 辅助采集操作

打开“页面与截图采集”，选择一个有效的自有商品。来源链接只保存为证据，不会因粘贴链接而主动访问。

支持 PNG/JPEG，文件不超过 6MB。页面内容和截图保存在租户隔离的 SQL 记录中，不通过公开静态目录暴露。每次读取证据均验证身份与归属。

未配置模型时，只识别以下明确标签：

```text
标题：品牌B保温杯
价格：99.00
规格：500ml 单只
促销：限会员且需领券
店铺：品牌B旗舰店
描述：可拆洗杯盖
```

离线模式不是 OCR：只有截图而没有文字时，状态明确提示人工补全。不会根据自有商品自动补造竞品的标题、规格或价格。允许人工填写核验后的候选，利用已保留截图完成入库。

## 多模态模型

沿用 MODEL_API_KEY、MODEL_BASE_URL、MODEL_NAME；可设置 VISION_MODEL_NAME 指定支持图片输入和结构化输出的模型。需要兼容 LangChain ChatOpenAI 的图片消息与结构化输出协议。

用户必须勾选“允许将文字和截图发送至已配置的模型服务”。未勾选只做本地标签提取/人工核验。应先裁剪个人身份、聊天、订单等无关内容，避免把这些内容交给模型。

提取 Schema 包含标题、价格、价格类型、规格、优惠条件、描述、店铺、字段依据与不确定项。模型没有工具权限。结构化校验失败或服务超时产生 EXTRACTION_FAILED，可继续人工核验，不冒充识别成功。候选重复提交会返回同一记录；修改材料后可重新提取。

## 安装浏览器

```powershell
python -m pip install --target .deps -r requirements-browser.txt
python scripts/install-browser.py
```

Chromium 下载到项目 `.browsers`，不会读取用户 Chrome 登录配置或个人 Cookie。环境变量 PLAYWRIGHT_BROWSERS_PATH 可覆盖路径。Compose 的基础镜像不含浏览器系统依赖，Linux 容器需单独安装 Playwright 所需系统库，并进行部署验证。

## 配置获准访问的站点

复制 `browser-profiles.example.json` 为 `browser-profiles.json`，按实际站点填写：

| 字段 | 说明 |
|---|---|
| enabled | 核验许可和页面后才设 true |
| name | 界面站点名 |
| domains | 精确域名白名单，包含必要的公开静态资源域名；不支持任意通配符 |
| search_url | 正常 HTTPS 搜索页面地址，以 {query} 放入 URL 编码关键词 |
| result_link_selector | 指向商品详情链接的 CSS 选择器，需要逐站核验 |
| min_interval_seconds | 任务最短间隔，实际不低于 60 秒 |
| page_interval_seconds | 页面间隔，实际限制在 2–10 秒 |

配置由服务器文件管理，不接受浏览器用户任意传入地址或选择器。当前没有内置声称可工作的淘宝选择器；页面结构和访问许可必须实际核验。未配置时界面清楚提示站点不可用，而不是显示已接通。

## 执行限制和暂停

- 每任务使用独立无历史会话；只访问 HTTPS 443，禁止 URL 内嵌账号。
- 每次请求及跳转检查精确域名和解析地址，禁止本地、私网及保留地址；总请求数不超过 120，禁止 Service Worker、WebSocket 和下载接受。
- 页面导航最多等待 20 秒，页面操作默认 10 秒；每个候选提取模型调用最多 40 秒且不重试。
- 401、403、429，以及登录/验证码/安全验证提示产生 PAUSED；不会继续抓取剩余详情。
- 审核员可确认暂停并关闭任务。该动作不是恢复或绕过验证；需重新核验许可后发起新任务，或转辅助采集。
- 服务器重启将中断任务标为 FAILED，不承诺浏览器步骤续跑。
- DNS 白名单检查不能替代生产级网络隔离，对抗 DNS 重绑定等风险应使用受控出口代理与网络策略；不将此原型描述为完整网络沙箱。

## 规格确认和入库

不同店铺 SKU 编码不通用。审核表要求人工填写实际观察到的规格并确认与自有商品一致，之后才映射至系统的比较键。原始规格、证据和采集 ID 保留。

候选内容并非可信事实。价格条件未知时保持“未核实”，不能计算确定到手价。审核通过后保存为竞品并建立关联；相同商品和规格已存在时只关联、不覆盖原档案。不会自动启用监控计划。

自有商品版本改变后旧候选不能批准，需重新采集。批准权限由服务端 reviewer/admin 角色限制；operator 可以提交候选但不能审核。候选与关联去重，证据跨租户不可读取。

## 模块与接口

- `app/capture.py`：输入校验、文字/图片提取适配、证据、候选和审核入库。
- `app/browser_capture.py`：站点配置、持久任务、访问检查、Playwright 执行与暂停。
- `web/capture.js`：上传、提交、候选查看和人工审核交互。
- `GET /api/v1/capture`：候选、浏览器任务、站点配置状态。
- `POST /api/v1/capture/assisted`：文字/截图提交。
- `GET /api/v1/capture/evidence/{id}`：授权读取证据。
- `POST /api/v1/capture/{id}/review`：核验并入库关联。
- `POST /api/v1/capture/{id}/reject`：拒绝未入库候选。
- `POST /api/v1/capture/browser/jobs`：异步浏览器任务。
- `POST /api/v1/capture/browser/jobs/{id}/review`：审核员确认暂停并关闭。

## 验证与边界

新增测试覆盖标签提取、入库幂等、人工确认门槛、跨租户证据、自有商品版本变化、未配置视觉模型、截图类型校验、私网访问拒绝、挑战识别、站点配置与暂停队列。

未配置真实视觉模型与获准站点，因此不宣称完成真实图片识别或淘宝浏览采集验收。浏览器页面结构变化可能导致空结果，错误不会伪装为有效商品。截图目前保存于 SQL，仅适合原型；生产应迁移至有访问控制和保留期限的对象存储。
